# Raccoon : versions stables

**RACCOON — La régie intelligente de votre programmation cinéma**, logiciel de CINE EUROPE.

Ce dépôt contient seulement les installateurs Windows des versions stables de Raccoon, avec leur fichier
`version.json`. Le code du logiciel n'est pas ici.

Raccoon installé dans un cinéma lit ce dépôt à l'ouverture et propose la nouvelle version, avec un court résumé
de ce qui change (« Installer la mise à jour » ou « Plus tard »). Réglages, programmation, licence et mots de
passe sont conservés et copiés avant chaque installation. Pour chercher à la main : **Aide › Rechercher une mise
à jour…** dans Raccoon.

Raccoon ne s'ouvre qu'avec une clé de licence délivrée par l'éditeur (ou pendant 30 jours d'essai).
